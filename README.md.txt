# Sales Performance Dashboard

## 📊 Project Overview

An interactive Sales Performance Dashboard developed using Microsoft Power BI to analyze sales performance, quantity, profit, regional performance, yearly trends, and category-wise sales.

## 🎯 Objectives

- Analyze overall sales, quantity, and profit.
- Compare performance across different regions.
- Analyze yearly sales and profit trends.
- Identify category-wise sales performance.
- Provide an interactive dashboard for quick business analysis.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📌 Dashboard Features

- KPI cards for Sales, Quantity, and Profit
- Region slicer
- Year slicer
- Sales & Profit by Year analysis
- Sales by Category analysis
- Detailed sales table
- Interactive tooltips
- Reset Filters button
- Interactive visual filtering

## 📈 Dashboard

The dashboard provides an interactive view of sales performance and allows users to explore the data using Region and Year filters.

## 💡 Key Learning

Through this project, I practiced data preparation, dashboard design, data visualization, interactive filtering, KPI creation, and business-oriented data analysis using Power BI.
